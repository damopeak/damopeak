## Hi, I'm Ayodamope 👋

I run **GA Goods**, a UK e-commerce distribution business, and I build the software that runs it. Everything here started as a real problem I had to solve: too much manual checking, too many inboxes and spreadsheets, not enough hours.

### What I build

- **Automation that replaces manual work:** email parsing, scheduled scrapers, API integrations and alerting that run unattended 24/7.
- **Data pipelines into something useful:** messy sources (order emails, bank exports, retailer sites, job boards) cleaned, matched and turned into dashboards and decisions.
- **Practical AI:** using LLMs where they earn their place (pulling deadlines out of email, a dashboard assistant), with the data treated as data, not instructions.
